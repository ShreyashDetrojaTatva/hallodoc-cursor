Admin has 3 main pages in navbar:

- My Profile (view/update)
- Records (search/filter past requests)

ADMIN DASHBOARD - REQUEST FLOW
==============================

Dashboard States (6):
1. New
2. Pending  
3. Active
4. Conclude
5. To-Close
6. Unpaid

Request Status Mapping to Dashboard States:
------------------------------------------
- New: Unassigned (1)
- Pending: Accepted (2)
- Active: MDEnRoute (4), MDONSite (5)
- Conclude: Conclude (6)
- To-Close: Closed (8), Cancelled (3), CancelledByPatient (7)
- Unpaid: Unpaid (9)

Original Request Statuses:
-------------------------
1. Unassigned = 1
2. Accepted = 2
3. Cancelled = 3
4. MDEnRoute = 4
5. MDONSite = 5
6. Conclude = 6
7. CancelledByPatient = 7
8. Closed = 8
9. Unpaid = 9
10. Clear = 10
11. Blocked = 11

Request Flow:
-------------
1. Request Created → New (Unassigned)
2. Admin assigns to physician OR cancels
3. Physician accepts → Pending (Accepted)
4. Admin sends agreement → Patient accepts → Active (MDEnRoute)
5. Patient rejects → CancelledByPatient
6. Physician generates encounter → Active (MDONSite)
7. Physician finalizes encounter → Conclude (Conclude)
8. Physician concludes care → To-Close (Closed)
9. Admin closes case → Unpaid (Unpaid) → FLOW COMPLETE
10. Admin clears the case → Request cleared. Not shown anywhere (Clear)

State-Specific Actions:
======================

NEW (Unassigned):
- Assign Request
- Cancel Request
- View Request
- View Documents (also upload new)

PENDING (Accepted):
- View Request
- View Documents (also upload new)
- View Notes
- Send Agreement
- Clear Case (move to Clear state)

ACTIVE (MDEnRoute, MDONSite):
- Send Order
- View Request
- View Documents (also upload new)
- View Notes

CONCLUDE (Conclude):
- Same as Active

TO-CLOSE (Closed, Cancelled, CancelledByPatient):
- View Request
- View Documents (also upload new)
- View Notes
- Close Case

UNPAID (Unpaid):
- View Request
- View Documents (also upload new)
- View Notes
